# Prompt: Improve & Expand Derawan Encyclopedia Website

Saya sedang mengembangkan **Derawan Encyclopedia**, dan project/struktur website yang sudah ada **HARUS dipertahankan**. Jangan membuat project baru, jangan mengubah framework utama, dan jangan melakukan refactor besar yang tidak diperlukan.

Tugas utama adalah **mengembangkan fitur dan halaman baru berdasarkan struktur, design system, komponen, dan pola arsitektur yang sudah tersedia di project saat ini**.

## Prinsip Utama

* Gunakan struktur project yang sudah ada.
* Pertahankan desain visual website yang sudah berjalan.
* Reuse komponen existing sebanyak mungkin.
* Jangan membuat UI yang terlihat seperti berasal dari website berbeda.
* Ikuti typography, color palette, spacing, card style, animation, navigation, responsive behavior, dan visual language yang sudah digunakan.
* Jangan menghapus atau merusak fitur yang sudah berjalan.
* Jika membutuhkan komponen baru, buat mengikuti pola komponen existing.
* Buat implementasi yang scalable sehingga data dapat diperbarui tanpa perlu mengubah layout secara manual.
* Gunakan placeholder untuk informasi/foto yang masih belum tersedia.
* Semua konten yang statusnya masih TBC atau belum dikonfirmasi jangan dianggap sebagai informasi final.

# 2. Integrasi / Referensi Allen Coral Atlas

Tambahkan bagian khusus pada Derawan Encyclopedia yang mengarahkan pengguna ke **Allen Coral Atlas**:

[Allen Coral Atlas](https://allencoralatlas.org/?utm_source=chatgpt.com)

Allen Coral Atlas merupakan platform pemantauan kesehatan terumbu karang global yang dikembangkan oleh tim yang dipimpin oleh Dr. Greg Asner.

Tujuan integrasi:

> Ketika pengguna ingin mengetahui kondisi atau kesehatan terumbu karang, Derawan Encyclopedia dapat memberikan rujukan ke Allen Coral Atlas sebagai sumber informasi eksternal.

## Penting

Jangan langsung membuat asumsi bahwa Allen Coral Atlas menyediakan API atau endpoint tertentu.

Pertama, periksa kemampuan integrasi yang tersedia.

Jika tersedia API/embed/deep-link resmi, gunakan mekanisme tersebut.

Jika tidak tersedia, implementasikan sebagai **external reference/integration page** yang tetap terasa sebagai bagian dari Derawan Encyclopedia.

Contoh konsep:

### Coral Reef Health

Berikan introductory text singkat mengenai pemantauan kesehatan terumbu karang.

Kemudian tampilkan:

* preview/visual yang diperbolehkan;
* tombol **Explore Allen Coral Atlas**;
* link ke Allen Coral Atlas;
* optional external-link indicator.

Jika memungkinkan secara teknis dan legal, sediakan deep link ke wilayah Derawan sehingga pengguna dapat langsung melihat area yang relevan.

**Jangan melakukan scraping atau menyalin data Allen Coral Atlas tanpa memastikan izin/ketentuan penggunaannya.**

# 3. Marine Bathymetry / Sea Depth Map

Tambahkan halaman atau section khusus untuk **peta kedalaman laut Derawan**.

Data bathymetry akan diberikan kemudian oleh stakeholder.

Untuk tahap sekarang:

* siapkan layout;
* siapkan map container;
* siapkan data structure;
* siapkan placeholder dataset;
* jangan membuat data kedalaman fiktif.

Halaman harus dirancang agar nantinya dapat menerima data seperti:

* GeoJSON
* GeoTIFF
* raster tiles
* vector tiles
* atau format geospatial lain yang sesuai dengan data yang diberikan.

Jika data memungkinkan, tampilkan:

* depth visualization;
* legend;
* zoom;
* pan;
* layer control;
* coordinate information jika relevan;
* optional depth query ketika user mengklik area tertentu.

Gunakan teknologi mapping yang **sudah digunakan project**, jika ada.

Jangan menambahkan library geospatial baru jika functionality tersebut dapat dilakukan dengan library yang sudah tersedia.

# 7. Data Architecture

Karena daftar contributor masih berkembang, jangan hardcode seluruh profile langsung di component.

Gunakan data-driven architecture.

Contoh struktur konseptual:

```text
contributors
├── founder
├── advisory-board
├── editorial-board
├── underwater-contributors
├── landscape-contributors
├── scientific-contributors
└── community-custodians
```

Setiap contributor minimal memiliki:

```text
id
name
role
organization
category
location
description
photo
status
sortOrder
featured
```

`status` dapat digunakan untuk:

* confirmed
* TBC
* coming-soon

Pastikan struktur tersebut mengikuti pola data/API/CMS yang sudah digunakan oleh project.
